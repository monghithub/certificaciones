## Descripción del candidato

The target candidate should have up to 6 months of exposure to AI/ML technologies on AWS. The target candidate uses but does not necessarily build AI/ML solutions on AWS.

## Recommended AWS knowledge

The target candidate should have the following AWS knowledge:

1. **CP.1** Familiarity with the core AWS services (for example, Amazon EC2, Amazon S3, AWS Lambda, Amazon Bedrock, and Amazon SageMaker AI) and AWS core services use cases
2. **CP.2** Familiarity with the AWS shared responsibility model for security and compliance in the AWS Cloud
3. **CP.3** Familiarity with AWS Identity and Access Management (IAM) for securing and controlling access to AWS resources
4. **CP.4** Familiarity with AWS service pricing models
